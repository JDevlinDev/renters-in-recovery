# Renters in Recovery

Tenant rights for Illinois sober living residents: know your rights, spot illegal "guest" contracts and same-day evictions, read the filings, and report bad operators.

```bash
npm ci
npm start        # dev server on http://localhost:4321
npm run push-gh  # build and deploy to GitHub Pages
```

Built with the Newbie FEM Starter Pack (Sass, BEM, Parcel).
